# Tidslåt – spiller

Hitster-inspirert øvespill for lytteprøven i musikk (10. trinn).
QR-kodene på kortene peker hit med bare et kortnummer (`#7`). Siden spiller låta
via en skjult YouTube-spiller, og viser aldri tittel, artist eller video.
Fasiten står på baksiden av de trykte kortene.

- `index.html` – spilleren (kameraskanner + avspilling)
- `jsQR.js` – QR-leser (MIT, https://github.com/cozmo/jsQR)
